# Dataset placement

Expected layout:
```text
dataset/BD3_split/
├── train/<class_name>/
├── val/<class_name>/
└── test/<class_name>/
```
Seven class folders: `algae`, `major_crack`, `minor_crack`, `peeling`, `plain`, `spalling`, `stain`.

The raw dataset is not included. Check licence and attribution before publishing or redistributing any images. Keep BFD-ML-4K separate from BD3 unless its use is explicitly documented.
